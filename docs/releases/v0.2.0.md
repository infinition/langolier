Built-in engine by default, and exported chatbots that update themselves from their own page.

### Embedded engine

- llama.cpp is now the default engine. Pick a curated tag under Engines, press Install, and the GGUF lands in the app cache: `qwen3:4b-instruct` (2.5 GB, recommended), `qwen3:8b` (5.0 GB), `qwen3:1.7b` (1.8 GB). Any GGUF path still works.
- Weights already pulled by Ollama are linked into the cache instead of being downloaded again.
- Idle models are unloaded after a configurable pause (5 minutes by default), so memory comes back without quitting the app.
- Ollama stays available as a provider; install and launch scripts treat it as optional.
- Exports and the light kit no longer need Ollama.

### Remote administration of exported chatbots

- Enable it in the profile before exporting, with a secret. A gear in the chat page footer then lets an administrator import a `.langolier`, restore any earlier version from a list, or delete one.
- Every bundle the chatbot ever ran is kept on the server, twenty at most, named, timestamped and deduplicated. The running version and the one the kit shipped with cannot be deleted.
- Nothing is ever downloaded from the page: no export, so the corpus and the API key stay on the server.
- Secret stored as a hash, five wrong attempts pause the routes for fifteen minutes, uploads stream to disk with a 1 GB cap.
- A bundle whose embedding model is missing on the host is refused with the reason, unless forced.

### Fixes

- Installing a bundle written by an older version no longer breaks the server: migrations run after every install.
- Administration settings belong to the deployment; restoring an older bundle does not lock the administrator out.
- The chat page follows the browser language, English or French.
- `Launch-Mac.command` prefers the installed app, asks before building, and closes its own Terminal window. `Stop-Ollama.command` added.
- macOS builds are universal (Apple Silicon and Intel).
- `LANGOLIER_DISABLE_TELEGRAM=1` keeps a test or a second instance from polling the bot.

### Assets

Installers for macOS (universal `.dmg`), Windows (`.exe`) and Linux (`.deb`, `.rpm`, `.AppImage`), plus `chatbot-runners-*.zip` holding the launchers used by exported chatbots.

macOS builds are ad hoc signed. On first launch, right click the app and pick Open.
