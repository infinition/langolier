First public release.

Langolier indexes documents, code, video and voice notes, then answers from them with citations. When nothing in the corpus supports an answer, it abstains instead of inventing one.

### In this release

- Desktop application for macOS (universal), Windows and Linux
- Ingestion: PDF with OCR fallback, DOCX, PPTX, XLSX, ODT, ODP, ODS, Markdown, text, CSV, JSON, notebooks, source files, subtitles
- Transcription of video and audio through whisper.cpp, voice memos included
- Retrieval: FTS5 BM25 and dense vectors, RRF fusion, optional judge model, abstention thresholds
- Engines: Ollama, local OpenAI-compatible servers, OpenAI, DeepSeek, Anthropic, or llama.cpp compiled in with a GGUF
- Watched folders in sync or hoover mode, local or on a mounted NAS
- Assistant profiles exportable as standalone chatbots, updated by dropping in a new `.langolier` bundle
- Telegram bridge and headless server mode, with a Docker image
- Interface in English and French

### Assets

`langolier-*` installers for each platform, plus `chatbot-runners-*.zip` holding the launchers used by exported chatbots. Drop a `.langolier` next to a launcher and it is a chatbot.

macOS builds are ad hoc signed. On first launch, right click the app and pick Open.
