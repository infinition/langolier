Sur un Mac recent, Langolier peut repondre avec le modele que le systeme porte deja. Rien a telecharger, rien a lancer.

### Le moteur Apple

- Sur macOS 26 et plus recent, un nouveau fournisseur, **Apple, sur ce Mac**, interroge le modele embarque du systeme via le framework FoundationModels. Aucun telechargement, aucun serveur a demarrer, aucun port ouvert, aucun espace disque: le modele appartient au systeme et il est partage avec toutes les applications qui le demandent.
- Environ 25 tokens par seconde sur un Mac M, premier token apres une seconde et demie. Au repos le systeme lui reprend la memoire, elle revient quand une question arrive.
- L'entree n'apparait que sur un Mac, et la page dit en clair pourquoi le modele ne peut pas repondre le cas echeant: Apple Intelligence desactive, Mac incapable de l'executer, ou modele encore en telechargement.
- Deux limites a connaitre. Le contexte est de 8192 tokens, partage entre les passages, la conversation et la reponse, donc les longs fils sont raccourcis. Et il n'ecrit que les reponses: Apple n'expose aucun embedding, la memoire continue de tourner sur le moteur compile dans l'application.

### Traductions

- La phase affichee pendant une reponse, les avertissements de recherche et le message d'index semantique partiel sont desormais traduits. Ce dernier portait ses nombres dans la phrase, ce qui empechait de la retrouver dans la table de traduction.
- Le statut du moteur dans la barre laterale reconnait le moteur Apple au lieu de le signaler comme a configurer.

### Construction

- La build macOS passe sur l'image `macos-26`, seule a porter le SDK qui contient FoundationModels, et une verification refuse desormais de publier une build macOS ou le moteur manquerait.
- Le pont Swift n'est compile que si le SDK le permet: sur une machine plus ancienne l'application se construit sans lui et signale simplement que le systeme est trop ancien.

### Assets

Installateurs pour macOS (`.dmg` universel), Windows (`.exe`) et Linux (`.deb`, `.rpm`, `.AppImage`), plus les `chatbot-runners-*.zip` utilises par les chatbots exportes.

Les versions macOS sont signees en ad hoc. Au premier lancement, clic droit sur l'application puis Ouvrir.
